# ArmorStandEditor ｜ Minecraft Plugin

A Minecraft Paper plugin that provides a GUI for editing Armor Stands.

## Features

- Edit Armor Stand equipment
- Change Armor Stand size
- Toggle arms
- Toggle base plate
- Toggle marker
- Edit Armor Stand pose
- Rotate Armor Stand
- Rename
- Toggle gravity
- Toggle visible
- GUI-based editing
- Preview (under development)

## Requirements

- Minecraft 1.21.4
- Paper
- Java 21+

## Current Status

This project is currently under development.
